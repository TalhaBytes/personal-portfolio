# Muhammad Talha Khan | TalhaBytes

Responsive, multi-page personal portfolio built with HTML, CSS, and vanilla JavaScript. The site includes light and dark themes, animations, client-side search, project filters, responsive layouts, and dedicated pages for experience, skills, education, and contact information.

## Included

- Home, experience/projects, skills, education, and contact pages.
- [QuizVerse](https://github.com/TalhaBytes/QuizVerse), an offline Windows trivia application built with Python, PySide6, and SQLite.
- [QuizVerse Windows release](https://github.com/TalhaBytes/QuizVerse/releases/latest) for users who want to run the packaged desktop application.
- [DevPulse](https://github.com/TalhaBytes/devpulse), a responsive GitHub developer dashboard built with HTML, CSS, JavaScript, and the GitHub REST API.
- Stock Price Prediction machine-learning project using Python, Linear Regression, Decision Tree, and XGBoost.
- Personal Portfolio Website built with HTML, CSS, and JavaScript.
- Network Administration internship experience at the Ministry of Foreign Affairs.
- Technical skills covering programming, AI/data science, databases, desktop development, web development, networking, testing, CI, and packaging tools.
- Email, LinkedIn, GitHub, and public resume links.
- TB icons, social preview image, page-specific metadata, custom 404 page, and `.nojekyll`.
